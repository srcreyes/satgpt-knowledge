# SatGPT Knowledge Portal

Static website for the [SatGPT Knowledge Portal](https://satgpt.net/), published via GitHub Pages.

Developed by the **Space Applications Section**, ICT and Disaster Risk Reduction Division, UN Economic and Social Commission for Asia and the Pacific (ESCAP).

## Repository Structure

```
satgpt/
├── index.html              # Home page
├── events.html             # Events & workshops
├── publications.html       # Research & publications
├── elearning.html          # Online courses
├── case-studies.html       # Case studies (coming soon)
├── about.html              # About & contributors
├── help.html               # Help & documentation (coming soon)
├── css/
│   └── shared.css          # Shared design system stylesheet
└── images/
    ├── logos/              # Partner & institution logos
    ├── elearning/          # Course thumbnails
    ├── publications/       # Publication covers
    └── [event folders]/    # Event photo galleries (e.g. 2026_Feb_LKA/)
```
